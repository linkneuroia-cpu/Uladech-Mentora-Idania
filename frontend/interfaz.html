Asistentes

Un asistente es un chatbot público ligado a una RD: responde usando las colecciones de esa RD, saluda al usuario por su nombre (vía Moodle), recuerda hasta 30 preguntas de la conversación, y guarda todo su historial.

Prueba de Asistente

Crear colección

Crea una nueva colección en Qdrant: como colección padre de una RD (fija su embedding maestro), hija de una RD que ya lo tiene, o normal (independiente, sin RD).

Formato recomendado: Curso_curid
🔑PadrePrimera colección de una RD — fija su embedding maestro.
🔗HijaOtro curso de una RD que ya tiene embedding maestro — lo hereda.
📦NormalSin RD — independiente, ningún asistente la encuentra.

API Reference — Gestión Qdrant

Endpoints de administración de colecciones expuestos por este servidor.

MétodoRutaDescripción
POST/api/collectionsCrea una colección (body: name, description, vector_schema, dense_size, distance)
GET/api/collections?detail=trueLista colecciones con esquema/puntos/estado
GET/api/collections/{name}Detalle de una colección
PATCH/api/collections/{name}Actualiza la descripción
DELETE/api/collections/{name}?force=boolElimina la colección
POST/api/collections/{name}/clearElimina todos los vectores, conserva el esquema
GET/api/collections/{name}/existsVerifica existencia
GET/api/collections/{name}/documentsLista documentos únicos vectorizados
DELETE/api/collections/{name}/documents/{filename}Elimina todos los chunks de un documento
GET/api/rag/retrieveRecuperación híbrida + rerank + boost, sin generación
POST/api/rag/answerPipeline completo del tutor (retrieve + rerank + boost + generación)
GET/api/config/{stage}Estrategia activa + catálogo de una etapa del pipeline RAG
POST/api/config/{stage}Cambia la estrategia activa de una etapa

Usuarios

Cuentas con acceso al gestor. Solo un administrador puede crear o eliminar usuarios.

Crear usuario
El acceso del docente ya no se pega a mano: lo genera la actividad del plugin idanIA en Moodle (mod_secureurl), que manda un token cifrado de un solo uso a {{ URL_PREFIX }}/login?token=....
Un docente sin ese token válido (y sin contraseña) no puede entrar por el formulario.
